## 💻 Local Development Setup

To run this website locally on your computer:

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view your live portfolio!

## 🚀 How to Deploy to Vercel (To Get Your Live Link for LinkedIn)

Apni website ko free mein live karne aur LinkedIn/Social platforms par link share karne ke liye ye aasan steps follow karein:

### Option A: GitHub + Vercel (Recommended & 1-Click Auto Updates)
1. Apne folder mein git initialize karke GitHub par naya repository banayein:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Muhammad Nasarullah Portfolio"
   git branch -M main
   git remote add origin https://github.com/MuhammadNasarullah575/nasarullah-portfolio.git
   git push -u origin main
   ```
2. [Vercel.com](https://vercel.com) par jayein aur apne GitHub account se login karein.
3. **"Add New Project"** par click karein aur apna `nasarullah-portfolio` repository select karein.
4. **"Deploy"** button dabayein! 60 seconds ke andar aapki website live ho jayegi:
   `https://nasarullah-portfolio.vercel.app` (ya custom domain).

### Option B: Vercel CLI (Direct Command Line Deploy)
```bash
npm i -g vercel
vercel
```
Prompt follow karein aur link instantly live ho jayega!
